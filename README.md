# 🎯 Quickie – Last Minute Interview Preparation

**Quickie** is a web-based platform designed to help job seekers prepare efficiently for interviews at the last moment.  
It provides interactive MCQ quizzes, instant results, and downloadable PDF resources tailored for IT and technical interviews.

---

## 🚀 Features

- 📝 **MCQ-Based Quizzes**  
  Practice topic-wise and role-based multiple-choice questions.

- 📊 **Instant Results & Performance Summary**  
  Get immediate feedback with score analysis after each quiz.

- 📄 **Downloadable PDF Notes**  
  Generate and download last-minute revision PDFs for selected IT fields and programming languages.

- 🔓 **No Login Required**  
  Start preparing instantly without registration or authentication.

- ⚡ **Fast & Responsive UI**  
  Optimized for desktop, tablet, and mobile devices.

---

## 🎯 Who Is This For?

- Final-year students preparing for placements  
- Freshers and experienced professionals  
- Developers preparing for IT interviews  
- Anyone needing **quick revision before an interview**

---

## 🛠️ Tech Stack

- **Frontend:** React, TypeScript  
- **Styling:** Tailwind CSS  
- **Build Tool:** Vite  
- **PDF Generation:** Client-side PDF utilities  
- **Deployment:** Vercel
